## ▶️ Running the Programs

Make sure you have a Java Development Kit (JDK) installed.

Check your installation:

```bash
java -version
javac -version
```

Compile and run an individual program from the directory containing the source file:

```bash
javac variables.java
java variables
```

Replace `variables` with the appropriate class name for the program you want to run. The filename and public class name must match when a public class is declared.
